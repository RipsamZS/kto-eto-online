# Структура проекта Kazo

Эта ветка содержит первый этап модульного разделения. Рабочий Worker и production deployment не менялись.

## Worker

- `src/index.js` — точка входа Worker, маршрутизация HTTP и подключение Durable Object.
- `src/durable-objects/GameRoom.js` — реализация Durable Object для игровых комнат.

## Игра «Кто это?»

- `public/games/who-is-it/index.html` — HTML-разметка и подключения модулей.
- `public/games/who-is-it/css/styles.css` — стили.
- `public/games/who-is-it/js/app.js` — общее состояние приложения, меню и каталог паков.
- `public/games/who-is-it/js/packs-manager.js` — редактор и управление паками.
- `public/games/who-is-it/js/online-room.js` — создание и подключение к комнатам.
- `public/games/who-is-it/js/gameplay.js` — игровой процесс, карточки, выбор персонажа и игровые события.
- `public/games/who-is-it/data/packs.js` — общие ключи хранения и инициализация массива встроенных паков.
- `public/games/who-is-it/data/packs/<pack>.js` — один встроенный пак на файл.

## Встроенные паки

- `animals.js` — животные
- `plants.js` — растения
- `professions.js` — профессии
- `landmarks.js` — достопримечательности
- `transport.js` — транспорт
- `space.js` — космос
- `food.js` — еда
- `fantasy.js` — фэнтези
- `minecraft.js` — Minecraft

## Порядок подключения

Сначала загружаются общие данные и отдельные паки, затем модули редактора, онлайн-комнат и игрового процесса, после них — основной модуль приложения. Это сохраняет общий браузерный контекст существующей игры.
