# Kaza Android

Android WebView wrapper for the live Kaza game website.

- Package: `com.kaza.app.debug` (debug build)
- Website: https://kaza.casual-online.workers.dev/
- Build: `gradle assembleDebug`
- Output: `app/build/outputs/apk/debug/app-debug.apk`

The APK loads the live game service, so rooms and multiplayer continue to use Kaza's existing backend.
